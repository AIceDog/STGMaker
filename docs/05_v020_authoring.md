# v0.20 制作职责与迁移说明

“子弹素材”保存静态外观、独立碰撞、场景和尾迹采样。“招式库”保存一套发射规则、弹体飞行过程与生命周期。“敌人”通过行为流程安排招式、移动、等待、并行和可复用的子流程。

0.20.1 的素材页面与动画粒子入口见[素材工作台说明](06_material_workbench.md)。外观和碰撞现在位于同一页，不再使用画面几何手柄。

素材修改影响所有引用它的招式；招式修改影响所有调用它的敌人。修改不会隐式复制素材。贴图是明确的外观类型，几何类型不加载图片；所有外观可以调整尺寸、旋转、偏移和颜色。碰撞单独调整，同样支持三角形、正多边形、自由多边形、圆环与扇形。

发射、命中、自然结束分别设置声音和特效。命中及自然结束可以调用招式或行为子流程；变形通过另一个招式取得新的弹体配置。伤害、生效前预警、结束后淡出和重复判伤间隔统一在招式的生命周期页设置。

原先的多段招式已经转换为独立招式与显式行为子流程；原先附在招式上的敌人移动已经写入调用动作，并提供可查看的演示行为。运行器只执行当前配置，没有发射组、素材运动继承或历史格式回退。

工程当前只读取格式12。原工程保留在工程外的 `F:\Portfolio\STGMaker.backup-20261016-v020-authoring-boundary`；一次性转换工具和转换报告也放在工程外。内置资源、项目制作资源和本机恢复草稿均按当前格式保存。

自动检查覆盖参数、引用、曲线、脚本配置、固定步长调度、归属回收、保存重开和导出启动。既有作品的视觉与手感仍需按制作人员的效果基准对照验收。
