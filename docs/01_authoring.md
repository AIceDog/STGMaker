# 开始制作

工坊以同一页面完成配置与预览。资源库包含静态子弹素材、弹幕招式、行为子流程、敌人/Boss、出场编队、关卡和障碍；游戏配置另外连接主角与世界地图。

**制作素材。** 在“招式 → 子弹素材”选择圆形、菱形、矩形、三角形、多边形、圆环、扇形或贴图。多边形默认规则轮廓，可调整边数或编辑自由顶点。所有外观都有尺寸、局部旋转、XY偏移和颜色；仅贴图模式加载图片。碰撞使用独立的几何与局部变换，没有贴图类型。圆环保留空洞，凹多边形保留凹口。

**制作攻击。** 招式只引用已有素材，保存一套发射规则、弹体飞行过程和生命周期。预警、淡出、伤害、命中频率、命中/结束后继、声音和特效均在招式编辑。素材修改会影响所有引用它的招式；招式修改会影响所有调用它的敌人。变形引用另一个招式的弹体配置，后继可调用招式或行为子流程，引用关系参与导入、删除保护和导出。

**组合攻击。** 在“敌人 → 行为子流程”使用释放招式、等待、并行和调用子流程。例如并行的两条分支分别立即释放红色扇形、等待1秒后释放蓝色追踪弹。节点可选择立即继续、等待发射完成或等待相关攻击全部结束。已经发出的弹体独立继续运行；显式清理操作才会删除对应实例。

**制作敌人。** 阶段使用动作、条件和随机分支编排。内置动作可组合移动、攻击和表现，分别设置前摇、执行、后摇与触发延迟。敌人自己的行为决定移动、招式与离场；关卡仅安排它何时、何处出现。已经发出的子弹保持自己的战斗坐标。

**使用脚本能力。** 选择自定义模块并填写声明的参数。动作切换为自定义实现时，内置配置保留为可切回的制作草稿，当前执行和引用图只采用生效的模块。手写脚本不会由表单重写。

**制作关卡与游戏。** 编队引用实体并定义数量、间隔、队形。关卡阶段提供卷轴、出场事件与结束条件。游戏页面连接战斗库、主角、地图地点与解锁条件；首个游戏与模块化示例位于 game/content。

**保存。** 保存 .tres 文档时，索引旁的 .assets 目录保存独立资产。索引与资产一起纳入版本管理；不要单独移动索引或删除其引用的文件。未完成配置可以保存为草稿，预览和构建会给出具体问题。撤销修改会话快照，不会自动回写磁盘。

**本机恢复草稿。** 启动时在工作台内提示未保存草稿；点击“查看草稿…”或“项目 → 恢复本机草稿…”再选择恢复。点击“稍后”或关闭恢复窗口会保留草稿，恢复后需要另存确认。

**预览。** 预览使用正式运行框架和固定步长。位置为设计坐标，时间为秒，角度字段的单位在表单及声明中标明。效果基准由制作人员对照检查；代码验收覆盖格式、引用、生命周期与运行行为。
