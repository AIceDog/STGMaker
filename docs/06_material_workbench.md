# 素材与招式制作界面（0.21.0）

素材负责外观、独立碰撞和可复用表现；招式负责节奏、弹道、伤害、声音与后续事件；敌人行为流程负责不同招式之间的顺序、等待和并行。子弹、激光、拖尾、召唤敌人按类型显示招式表单，召唤引用敌人资产。已有区域素材和招式仍能编辑。

## 外观与碰撞

两套独立几何同页编辑，基础属性直接展开。“大小”“局部偏移”的标签保持横排，X/Y 始终同行；窄面板放不下整行时，完整标签移到上一行。局部旋转、偏移与颜色不改变飞行方向，外观修改不会隐式改变碰撞。可显式复制外观几何到碰撞，之后仍独立编辑。不提供画面几何拖拽按钮。

外形明确区分几何与贴图。非贴图形状不加载图片或贴图动画；碰撞没有贴图类型。几何包括圆形、菱形、矩形、三角形、自定义多边形、圆环和扇形。已有自定义轮廓保留，新多边形按边数生成。

## 贴图与阶段动画

普通子弹选择“贴图”后，直接在外观内配置四类表现：运行中、刚发射 / 前摇、碰撞 / 命中、未命中消失 / 后摇。运行中只有一个入口，选择静态图片或 GIF，两者互斥；其他阶段可不填，静态子弹只填运行中图片即可。

文件先放入当前 Godot 工程。选择 GIF 时解码为 Godot 原生 `SpriteFrames`，使用 `default` 动画保存合成帧与逐帧时长，帧贴图采用无损可移植纹理。支持透明、局部帧、交错行与恢复背景 / 前帧。帧资源随素材通过正式事务保存、重开、再次保存和导出，运行时无需原始 GIF 或解码器。也可选择静态图片或带有 `default` 动画的原生帧动画 `.tres`。零时长按 0.01 秒处理；尺寸上限 2048×2048、文件上限 64 MB、最多 512 帧、全部合成帧上限 16,777,216 像素。

动画只随正式模拟步长推进，暂停不推进，重播重建实例。运行中循环；前摇大于零时发射动画适配前摇时长，没有前摇时按动画自身时长播放，再进入运行动画。自然结束动画适配后摇时长，后摇为零时直接回收。命中动画在命中位置独立收尾，不阻止原弹体回收，也不触发自然结束。未配置的阶段使用运行中外观。

贴图激光提供攻击前摇、攻击中、攻击后摇三类表现。几何激光使用现有预警透明度、执行期尺寸曲线和淡出；第一版未增加专门的前后摇宽度曲线控件。

解码依据 [GIF89a 规范](https://www.w3.org/Graphics/GIF/spec-gif89a.txt)。GIF（Graphics Interchange Format）及其服务标志归 CompuServe Incorporated 所有。

## 粒子与表现扩展

普通子弹的“粒子 / 扩展”页配置刚发射、运行中、命中后三类粒子，所有普通子弹外形均可使用。运行粒子跟随弹体，前摇结束后开始，后摇时停止新增粒子；发射与命中粒子留在事件位置，按设置时间回收。场景根节点为 Node2D，可含 CPUParticles2D 或 GPUParticles2D，使用正式模拟时钟。激光不提供这些粒子字段。

“表现扩展（技术策划）”保留可选 Node2D 场景和 AnimationPlayer 引用，供特殊美术使用；普通帧动画与粒子使用专用配置。“同时显示基础外观”允许叠加或替代几何 / 贴图，独立碰撞保持有效。高级运行场景继续遵守正式弹体接口。示例见 `examples/presentation/pulse_sparks.tscn`。

素材阶段表现自动播放。招式“音效 / 特效”配置额外的招式事件表现，同一个效果只需在一处配置。

## 招式的三个分区

| 区域 | 职责 |
| --- | --- |
| 子弹节奏 | 每颗弹体生成后的前摇、自然结束后的后摇 |
| 发射节奏 | 开始延迟、每轮数量、轮数、轮间隔、齐射 / 分组、每组数量、组间隔、发射实现 |
| 弹道 | 生成位置与偏移、出生排列、初始方向、规律旋转、高级飞行过程 |

每轮数量只有一个编辑入口，排列和方向分布读取同一份数量。发射实现位于发射节奏内部。脚本发射模块自行决定轮内生成算法和时刻，读取公共数量输入，不叠加内置分组调度。

分组是同一轮内部按批次发出，末批保留余数。例如 12 颗、每批 3 颗、间隔 0.1 秒，对应 0、0.1、0.2、0.3 秒。零组间隔同时发完。出生点、扇形方向、逐颗螺旋按完整轮序号计算，分组不重新编号；同一轮的空间规划和每轮瞄准在该轮开始时取样。

开始延迟相对本次招式调用时计算，结束后才创建第一批弹体。前摇从每颗弹体生成后开始，不移动、不判伤，与敌人动作前摇分开。轮间隔按相邻轮第一批起点计算，短于分组时长时允许两轮重叠。不同招式的组合仍由敌人行为流程组织。

“轮次变化与随机”区域已移除，新制作不提供随机方向与摆幅控件。规律的逐颗 / 逐轮方向递增归弹道。已有资源的随机、单轴取点等正式参数继续执行并显示提示，不清空原数据，也没有历史格式回退。FlyTiger 两套模板库本轮不适配或重制。

“攻击原点”改为“子弹生成位置”，激光和召唤使用对应名称。位置偏移使用战斗坐标，X 向右、Y 向下；固定坐标原点为画面中心。重新选择生成基准使用完整 X/Y。“高级弹道 · 飞行过程”保留现有步骤，详细制作流程待后续设计。

## 激光、拖尾和召唤

激光二选一：指定位置生成，或沿弹道发射。定点模式使用同一弹体运行器与阶段时钟，不执行运动能力，显示攻击中持续时间。切换为定点会把原飞行步骤合并为等长停留步骤，可撤销。两种模式均保留前后摇。

拖尾显示最大路径长度、生成时长、每段保留时间和前后摇，不复制普通子弹的发射、方向表单。长度按战斗坐标路径距离计算，0 表示只由每段寿命限制；超长时裁剪最旧段。路径来自敌人真实移动，瞬移断开，停止生成后旧段继续收尾。宽度、碰撞、采样仍在素材中配置，最终界面待细化。

召唤是并列招式类型，只引用敌人定义，不要求子弹素材。提供指定位置召唤、发射出去两种模式。前摇结束敌人才出现；发射模式第一版使用入场速度和时间，入场完成后启动敌人自己的正式行为运行器，保持终点坐标，不同时运行两套移动。召唤声音、特效在招式中配置；生命值、碰撞、动画和 AI 在敌人资产中制作。存活上限从召唤实例创建时计算，包含前摇和入场。

## 验证与资源格式

完整测试包含分组时序和取消、余数、两种生成模式、召唤接管、路径长度、GIF 像素独立对照、帧时长、事务保存、重开及独立导出。真实渲染检查覆盖大字号横排、GIF 绑定及四类招式切换。

资产格式仍为 12；新增字段使用当前模型默认值，不增加格式兼容分支。本轮不批量重存既有素材、招式、曲线或扩展脚本。
