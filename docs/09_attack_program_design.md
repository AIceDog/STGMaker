# Attack Program SDK 设计记录

此文保留最初设计方向。2026-10-18 已按用户授权实施第一版，当前实现以项目代码为准。以下“建议/待实施”是历史设计，不能当作当前 API 文档。

首版明确的取舍：程序内部 Stage 由代码定义；预设人工决定开放参数；一个预设绑定一种几何能力与一份素材；origin 跟随既有动作原点，initial_origin 保留初始位置；普通停止程序是否清屏遵守敌人 clear_on_end，实体程序可独立收尾。完整清屏、失败和退出关闭归属实体。格式保持 13，不恢复自定义发射制作入口。

## 选择方向

采用“稳定运行 API + GDScript 招式实现 + 程序声明参数”的方式。固定的是运行契约，每个招式只声明自己的参数。策划选程序后看到所需字段，布局可由静态场景和共用组件承载。不要为所有招式写一张不断膨胀的固定属性表，也不要让程序接管渲染、伤害或节点回收。

参数属于资产，执行状态属于实例。同一个程序资产可以被多个敌人同时调用，每次都有独立状态、随机流和实体归属；禁止把运行中的角度、句柄或计时写回 Resource。

## 稳定契约

以下均是建议的新接口名称，不是当前仓库已有或可直接调用的 API。

| 契约 | 建议能力 | 明确语义 |
| --- | --- | --- |
| 调用环境 | origin / origin_transform / owner / target | 战斗世界坐标，XY 中 Y 向下；角度与角速度 API 用弧度，策划 UI 可显示度数；目标可失效，查询返回有效性 |
| 时间 | elapsed / delta | 统一固定模拟步长，不读真实时间；暂停停止，倍速只影响调度，重播从同一初始状态开始 |
| 随机 | random_range / random_int | 每次攻击具有可复现种子；实体子流按稳定序号派生，不使用全局随机数，不受绘制帧率影响 |
| 归属与伤害 | team / source / damage_profile | 伤害与命中策略由宿主传入，程序只能通过运行 API 创建攻击，不能绕过阵营、命中频率和碰撞规则 |
| 生命周期 | finish / cancel | finish 表示不再运行本程序；遗留实体必须有有限寿命或独立实体程序；cancel 立即取消归属攻击和判伤，并使句柄失效 |
| 错误 | issue + 参数路径 | 不支持的能力、无效资源、非有限几何、超出配额均定位到程序与参数；完整检查/构建提前拒绝不支持配置 |

调用原点是释放时的初始变换；跟随发射者应显式查询当前 owner_transform。丢失目标时由程序声明“保持方向 / 完成 / 取消”等策略，不把敌人行为流程的前摇与收招偷偷放回招式。

## 两种执行作用域

- Attack-level：每次招式释放一个实例，负责整体排布、批次、全屏雷击或多束激光。start 建立初始状态，tick 按模拟时钟运行，完成或取消只清理一次。
- Entity-level：每个攻击实体一个实例，负责单颗跟踪、激光生长或折线演化；接收实体只读配置与自己的状态，结束不能操作同招式的其他实体。

二者使用不同上下文类型和权限。Attack-level 可以创建实体并挂接实体程序；Entity-level 默认只更新自身。需要生子弹时应声明额外能力和配额，不能默认无限递归生成。敌人的行为流程调用攻击实例并可等待“程序结束”或“归属攻击清空”，两种完成条件不能混为一谈。

## 持久实体句柄

建议句柄包含 battle_id、owner_execution_id、slot、generation。创建一次并持续更新，不能每帧销毁重建。更新检查宿主、归属及代次；实体已销毁、槽位复用、战斗退出后，旧句柄操作返回失败并定位来源，不访问释放后的 Node。

| 类型 | 创建输入 | 持续更新 | 运行时责任 |
| --- | --- | --- | --- |
| Body | 素材 ID、初始变换、速度、有限寿命 | transform / velocity | 普通弹体表现、碰撞、伤害、回收 |
| Beam | 激光素材、起终点、宽度、有限寿命 | endpoints / width | 激光外观、连续碰撞及命中节奏 |
| Polyline | 表现定义、点集、宽度、段寿命策略 | points / width / append_sample | 雷电和动态路径的表现、分段碰撞与回收 |
| Area | 区域素材、变换、尺寸或形状、有限寿命 | transform / shape | 范围攻击及命中规则 |

建议共用 spawn_body、create_beam、create_polyline、create_area、set_transform、set_points、set_width、destroy；具体类型仍有专属更新方法。Body、Beam、Polyline、Area 不强行变成一种 Node2D 实现。所有输入检查有限数、最大点数、宽度、寿命和实体数量，批量提交在固定步边界生效。范围和折线的表现与碰撞使用同一份已验证几何数据。

Polyline 必须声明用途：一次生成的雷电折线与不断采样、按段消退的拖尾具有不同寿命和命中节奏。共享点集接口，分别选择正式运行器。曲线激光素材制作功能不因此恢复。

finish 停止本程序的后续命令，已生成的 Body 可以继续自己的有限寿命；仍需每帧更新的持久 Beam/Polyline 应由实体程序接管，或结束时销毁。不能留下永久判伤实体。cancel 与清屏撤销判伤并释放实体；附属粒子遵守宿主的自然排空或强制清理规则。取消、完成、战斗退出不能重复执行 stop。

## 参数声明和制作 UI

参数声明独立于执行脚本状态，包含稳定字段键、中文标题、类型、默认值、单位、范围、可选值、可见条件、资源引用类别和说明。优先复用现有 float/int/bool/string/resource_id；向量、曲线、数组只有出现实际需求才扩展声明协议。参数变化仅重建受影响字段；普通数值修改保留静态表单实例。程序可提供可选的属性场景，但字段仍通过稳定键绑定，移动容器不影响配置。

导入、删除保护、校验和构建依赖必须从同一资源引用声明收集。构建包含选中程序实现及实际引用资源，排除编辑器。SDK 实施时单独设计资产升级，本轮不增加占位字段或旧格式兼容。

## 四个接口核对案例

| 案例 | 程序参数与执行 | 核对出的缺口 |
| --- | --- | --- |
| 普通子弹 | 速度、发射角、数量；攻击实例 spawn_body，实体按固定步更新位置 | 初速度使用世界还是调用局部坐标必须显式；当前运动能力可作为第一参考，无需另写渲染 |
| 持续旋转激光 | 长度、宽度、角速度、持续时间；创建 Beam 句柄，tick 更新起终点 | 需要正式激光几何更新 API、宽度与碰撞同步、宿主消失和取消策略；当前素材长度宽度不等于此新 API |
| 随机雷电 | 点数、偏移、持续时间、伤害节奏；独立随机流一次创建折线，有限寿命后回收 | 需要非有限/重复点处理、点数上限、折线碰撞、分叉配额；分叉归同一攻击实例，不能越权操作其他实体 |
| 动态拖尾 | 采样距离、宽度、段寿命、最大长度；实体移动时 append_sample，删除过期段 | 现有拖尾执行器可复用；需要稳定的增量点集接口、段时间戳、停止采样后自然消退，避免每帧复制整条路径 |

后续按这四个案例逐步实施和验证 SDK，再决定 Modifier、程序组合、复杂曲线参数或节点图。当前保留已有能力会话及运动实现；不把设计示例误当成可运行功能。
